# PD-Element X

**فارسی** | [English](README.en.md)

سرور پیام‌رسان خودتان را با پشتیبانی از Element X، نسخه وب و تماس صوتی و تصویری راه‌اندازی کنید. شامل Synapse، PostgreSQL، Element Web، LiveKit، MatrixRTC و HTTPS خودکار.

Element X اپلیکیشن موبایل است؛ این پروژه زیرساخت سرور آن را نصب می‌کند.

## پیش‌نیازها

- Ubuntu 22.04 یا 24.04، معماری amd64 یا arm64 و دسترسی root؛ نصب روی Ubuntu 22.04 amd64 آزمایش شده است.
- دامنه و IPv4 عمومی ثابت؛ برای شروع سبک ۲ هسته، ۴ گیگ RAM و ۳۰ گیگ دیسک پیشنهاد می‌شود.
- حداقل ۸ گیگ فضای خالی و دسترسی به مخازن Ubuntu، Docker و GHCR.
- ترجیحاً سرور تازه؛ پورت 443 آزاد باشد. سرویس‌های وب موجود ممکن است به تنظیم دستی نیاز داشته باشند.

## دامنه و پورت‌ها

| نوع | نام | مقدار |
|---|---|---|
| A | matrix | IP سرور |
| A | element | IP سرور |
| A | rtc | IP سرور |
| A | turn | IP سرور |

در Cloudflare همه **DNS only** باشند. برای این چهار نام رکورد AAAA نگذارید. دامنه اصلی نیازی به تغییر ندارد.

در فایروال سرور و پنل VPS این پورت‌ها را مجاز کنید:

| پروتکل | پورت‌ها |
|---|---|
| TCP | پورت SSH خودتان، 80، 443، 7881 |
| UDP | 3478، 50000–50200 |

پورت‌های داخلی و پایگاه داده را عمومی باز نکنید. نصب، قواعد لازم را به UFW فعال اضافه می‌کند؛ UFW غیرفعال را فعال نمی‌کند.

## نصب

با root وارد SSH شوید و اجرا کنید:

```bash
apt-get update
apt-get install -y curl python3
bash <(curl -fsSL https://raw.githubusercontent.com/Mehdi682007/element-x-server-installer/main/install.sh)
```

گزینه **۱** را انتخاب و دامنه و ایمیل اختیاری را وارد کنید. IPv4 عمومی خودکار تشخیص داده می‌شود؛ فقط در صورت شکست تشخیص، ورود دستی درخواست می‌شود. IP نصب موجود حفظ می‌شود. برای تعیین IP خاص می‌توانید منو را با `sudo env PUBLIC_IP=203.0.113.10 pd-element-x` اجرا کنید؛ آدرس نمونه را جایگزین کنید. برای بازکردن مجدد منو:

```bash
sudo pd-element-x
```

## حساب و ورود

- گزینه **۳**: ساخت کاربر معمولی؛ **۲**: ساخت ادمین؛ **۴**: رمز تصادفی.
- اطلاعات ادمین اولیه در `/opt/element-stack/admin-credentials.txt` ذخیره می‌شود؛ آن را خصوصی نگه دارید.
- گزینه **۱۸**: نمایش اطلاعات ذخیره‌شده مدیر، تغییر رمز یا ساخت مدیر با نام کاربری جدید. تغییر رمز به ورود ادمین نیاز دارد؛ اگر رمز را فراموش کرده‌اید، از همین گزینه مدیر جدید بسازید. نام کاربری Matrix قابل تغییر نیست؛ حساب جدید تاریخچه و عضویت‌های حساب قبلی را به ارث نمی‌برد و حساب قبلی حفظ می‌شود. رمز تغییرکرده خارج از ابزار ممکن است با مقدار ذخیره‌شده فرق داشته باشد.
- در Element X سرور را روی `https://matrix.example.com` تنظیم کنید.
- نسخه وب: `https://element.example.com`؛ `example.com` را با دامنه خودتان جایگزین کنید.

ثبت‌نام عمومی پیش‌فرض بسته است. گزینه **۹** آن را باز یا بسته می‌کند؛ ساخت حساب توسط مدیر در هر دو حالت ممکن است. در حالت باز، کاربران از `https://element.example.com/#/register` ثبت‌نام می‌کنند. تأیید ایمیل و CAPTCHA تنظیم نشده‌اند. تغییر ثبت‌نام، Synapse را کوتاه restart می‌کند؛ حساب‌های موجود حفظ می‌شوند.

حساب ادمین در Element پنل مدیریت جداگانه ندارد؛ مدیریت سرور از منوی SSH انجام می‌شود. Recovery Key حساب خود را جداگانه ذخیره کنید.

## مدیریت و نگهداری

| گزینه | کاربرد |
|---|---|
| ۵ تا ۷ | فعال‌سازی حساب غیرفعال، فهرست و غیرفعال‌سازی کاربران |
| ۸ | محدودیت آپلود |
| ۱۰ و ۱۱ | بررسی سلامت و رفع مشکلات رایج |
| ۱۲ و ۱۳ | بکاپ و بازیابی |
| ۱۴ | عیب‌یابی تماس |
| ۱۵ | به‌روزرسانی Element Web؛ اپ موبایل از فروشگاه به‌روز می‌شود |
| ۱۶ | حذف سرویس با تأیید؛ بکاپ‌ها نگه داشته می‌شوند |

بکاپ‌ها در `/var/backups/element-stack` ذخیره می‌شوند؛ آن‌ها را خارج از سرور کپی کنید و فضای دیسک را بررسی کنید. بکاپ، Synapse را موقتاً متوقف می‌کند. بازیابی به نصب آماده با همان دامنه/IP و نسخه اصلی PostgreSQL نیاز دارد؛ فقط بکاپ مورد اعتماد را بازیابی کنید. پوشه قبلی پس از بازیابی نگه داشته می‌شود و فضا مصرف می‌کند.

قبل از به‌روزرسانی یا نصب مجدد بکاپ بگیرید. نصب مجدد، تنظیمات تولیدشده را بازسازی می‌کند و دامنه/IP نصب موجود را تغییر نمی‌دهد. مهاجرت نصب‌های دیگر و ادغام دیسک خودکار نیست.

تماس را با دو حساب روی دو دستگاه و دو شبکه متفاوت امتحان کنید؛ بررسی سلامت جای تست صدا و تصویر را نمی‌گیرد. گواهی‌ها خودکار تمدید می‌شوند؛ restart سرویس تماس برای بارگیری گواهی جدید ممکن است تماس فعال را کوتاه قطع کند.
